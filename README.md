# Pong FX

Pong FX is a two-player arcade game that adds energy-powered abilities to classic paddle tennis. Play on one screen and race to seven points. The browser draws the court and effects on a canvas, and the Web Audio API generates the sound effects.

## Play locally

1. Download or clone the repository.
2. Open [`index.html`](index.html) in a browser.
3. Select **Começar** to start. After a match, select **Jogar de novo** to play again.

The game runs from a single HTML file with embedded CSS and JavaScript. The in-game menus are in Brazilian Portuguese.

## Controls

| Player | Move | Abilities |
| --- | --- | --- |
| Left | `W` / `S` | `X` Black Hole, `C` Dark Shield, `7` Gravity Pulse |
| Right | `↑` / `↓` or `I` / `K` | `Z` Freeze, `V` Speed Overdrive, `9` Prism Mode |

Watch the energy meters before using an ability. Press `8` to toggle developer mode and try abilities with unlimited energy. On a touchscreen, drag on the left or right half of the court to move that paddle.
